# Блокировка учётной записи

Администратор может заблокировать участника на странице редактирования пользователя: `/admin/users/<user_id>/edit` (форма «Заблокировать пользователя» с обязательной причиной).

## Поля в `users`

| Колонка | Назначение |
|---------|------------|
| `is_blocked` | `1` — доступ к сайту ограничен |
| `blocked_reason` | Текст причины (показывается пользователю) |
| `blocked_by` | `user_id` администратора, выполнившего блокировку |
| `blocked_at` | Время блокировки (UTC) |

Колонки добавляются legacy-миграцией `003_legacy_columns.py`.

## Поведение для заблокированного пользователя

После успешной авторизации через GWars (или `login_dev` на localhost) пользователь с `is_blocked = 1` попадает на **`/account/blocked`**.

На этой странице отображаются:

- причина блокировки;
- дата и автор блокировки (если заданы);
- текст с предложением обратиться к администрации при несогласии;
- список пользователей с ролями **admin** и **moderator**: имя и ссылка **«Персонаж в GWars»** (`https://www.gwars.io/info.php?id=<user_id>`), без email и мессенджеров (на `/contacts` по-прежнему полные контакты).

Доступные действия: просмотр этой страницы и **выход** (`/logout`). Сайдбар и ссылка на профиль в шапке скрыты.

### Глобальный gate

`register_blocked_user_gate` в [`gwadm/services/user_block.py`](../gwadm/services/user_block.py) (подключается в [`gwadm/factory.py`](../gwadm/factory.py)) на каждом запросе:

- если в сессии есть `user_id`, пользователь заблокирован и **нет** режима impersonation — редирект на `/account/blocked`;
- для JSON/API-запросов — ответ **403** с телом `{"success": false, "code": "account_blocked", ...}`.

Исключения: `static`, `/health`, `/account/blocked`, `/logout`.

Для заблокированных не обновляется `last_seen` (presence).

### Impersonation

Если администратор управляет пользователем (`session['impersonation_original']`), gate **не** применяется — админ может проверить сайт от имени заблокированного.

## Рассылки

Заблокированные исключаются из выборок получателей рассылок (`gwadm/services/broadcast_queue.py`, формы в админке).

## Публичный профиль

На странице профиля других пользователей блок «Пользователь заблокирован» остаётся в [`templates/view_profile.html`](../templates/view_profile.html) (информационный баннер для посетителей).
