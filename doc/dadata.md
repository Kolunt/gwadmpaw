# DaData (подсказки адреса)

Интеграция для автозаполнения почтового адреса при регистрации на мероприятие и в [редактировании профиля](/profile/edit).

## Настройка в админке

1. `/admin/settings` → вкладка **Интеграции** → **DaData**.
2. Указать **API-ключ** (Token) и **Secret**, нажать «Проверить ключи».
3. Включить чекбокс **DaData интеграция включена** (доступен только после успешной проверки).

В БД (`settings`):

| Ключ | Назначение |
|------|------------|
| `dadata_api_key` | Token |
| `dadata_secret_key` | Secret |
| `dadata_verified` | `1` после успешной проверки |
| `dadata_enabled` | `1` — подсказки включены на сайте |

## Поведение на сайте

При `dadata_enabled` и `dadata_verified` на шаге адреса модалки регистрации и в блоке «Адрес» профиля показывается переключатель **«Я из России»** / **«Я не из России»** и поле **«Поиск адреса»** (блок DaData). Подсказки и поиск видны только при выборе «Я из России». При «Я не из России» блок поиска скрывается; уже введённые поля адреса **не очищаются**.

Начальное состояние переключателя при открытии формы берётся из поля **страна** (`country`): пустое значение или `россия` / `russia` / `рф` / `ru` (без учёта регистра) — Россия; иначе — «не из России». Отдельного поля в БД нет.

Пользователь выбирает подсказку — заполняются поля индекс, страна, город, улица, дом, корпус/строение, квартира. Поля остаются редактируемыми. В поле **улицы** отдельные подсказки (только для «Я из России»): учитывают индекс и город, а после выбора адреса в общем поиске — FIAS населённого пункта. Если пользователь меняет страну вручную, переключатель и видимость DaData синхронизируются с полем страны.

Подсказки ориентированы на **адреса РФ**. Для других стран ввод вручную.

## API (прокси)

Браузер **не** получает Secret. Запросы идут на сервер:

- `POST /dadata/suggest/address`
- Требуется авторизация (`session`) и CSRF (`X-CSRF-Token` или поле `_csrf_token` в JSON).
- Body: `{"query": "москва ленина"}` (до 200 символов).
- Поиск **улиц в выбранном населённом пункте**: `{"query": "ленина", "street_only": true, "locations": [{ "city_fias_id": "...", "settlement_fias_id": "..." }]}` — границы DaData `street`…`house`. `locations` можно собрать из поля `location` ответа после выбора адреса в общем поиске; иначе — индекс и город из формы.
- Ответ: `{ "success": true, "suggestions": [{ "value", "label", "fields": { ... }, "location": { ... } }] }`.

Сервер вызывает `https://suggestions.dadata.ru/suggestions/api/4_1/rs/suggest/address`.

Реализация: [`gwadm/services/dadata.py`](../gwadm/services/dadata.py), маршрут в [`gwadm/blueprints/integrations.py`](../gwadm/blueprints/integrations.py).

Фронт: [`static/js/dadata-address.js`](../static/js/dadata-address.js).

## Маппинг полей DaData → форма

| Поле формы | DaData `data` |
|------------|----------------|
| `postal_code` | `postal_code` |
| `country` | `country` |
| `city` | Склейка частей адреса (с типом, если есть): `city` + `settlement`; без города — `area` + `settlement` или только `settlement` / `area` / `city`. Если в `data` нет `settlement`, но в тексте подсказки есть хутор/деревня/станица и т.п. — последний фрагмент строки подсказки дописывается к городу |
| `street` | `street_with_type` или `street` |
| `house` | `house` |
| `building` | `block` |
| `apartment` | `flat` |

## Проверка ключей (админ)

`POST /admin/settings/verify-dadata` — отдельный от подсказок; использует Profile Balance API (см. [`verify_dadata_api`](../gwadm/services/telegram.py)).
