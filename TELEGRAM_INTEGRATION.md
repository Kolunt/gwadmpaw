# Инструкция по настройке интеграции Telegram

## Для администратора

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните **токен бота** (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Настройка в админ-панели

1. Перейдите в **Админ-панель → Настройки → Интеграции → Telegram**
2. Введите **токен бота** в поле "Токен бота"
3. (Опционально) Укажите **Chat ID** для отправки уведомлений администратору
4. Нажмите **"🔍 Проверить подключение"**
   - Система автоматически:
     - Проверит токен через Telegram API
     - Настроит вебхук для получения сообщений от пользователей
     - Отправит тестовое сообщение (если указан Chat ID)
5. После успешной проверки включите **"Включить интеграцию Telegram"**

### 3. Настройка вебхука

Вебхук настраивается автоматически при проверке бота. URL вебхука:
```
https://yourdomain.com/telegram/webhook
```

Если автоматическая настройка не сработала:
1. Скопируйте URL вебхука из настроек
2. Откройте [@BotFather](https://t.me/BotFather) в Telegram
3. Отправьте команду `/setwebhook`
4. Вставьте скопированный URL

### 4. Настройка базового URL

В поле **"Базовый URL сайта"** укажите **канонический** адрес сайта (например: `https://gwadm.ru`). Это нужно для формирования ссылок в боте и webhook.

Зеркала GWars (несколько доменов для входа) на Telegram не влияют: бот всегда использует `site_url`, а не домен, с которого пользователь зашёл через GWars. См. [GWARS_DOMAINS.md](GWARS_DOMAINS.md).

## Для пользователей

### Привязка Telegram аккаунта

Чтобы пользователи могли получать сообщения в Telegram, они должны привязать свой аккаунт:

1. Пользователь заходит в свой **Профиль → Контакты**
2. В разделе **"🤖 Telegram бот"** нажимает **"Получить код верификации"**
3. Система генерирует 6-значный код
4. Пользователь:
   - Открывает бота в Telegram (ссылка предоставляется)
   - Отправляет боту код верификации
   - Или использует команду `/verify <код>`
5. После успешной верификации аккаунт привязан

### Получение сообщений

После привязки аккаунта пользователи могут:
- Получать уведомления от системы
- Использовать команды бота (`/menu`, `/events`, `/assignments` и т.д.)
- Получать рассылки через Telegram (если выбрана опция "Telegram" при рассылке)

## Как работает отправка сообщений

### 1. Через рассылки (Broadcasts)

При создании рассылки администратор может выбрать метод доставки:
- **Email** - отправка на email пользователя
- **Telegram** - отправка в Telegram

Для Telegram используется поле `telegram` из профиля пользователя:
- Если начинается с `@` - используется как username
- Иначе - используется как chat_id

**Важно:** Для рассылок через Telegram пользователь должен указать свой Telegram username или chat_id в профиле (поле "Telegram" в разделе контактов).

### 2. Через привязанный аккаунт

Если пользователь привязал Telegram через верификацию:
- Система сохраняет `telegram_chat_id` в таблице `telegram_users`
- Сообщения отправляются на этот chat_id
- Это более надежный способ, так как chat_id не меняется

### 3. Проверка статуса интеграции

В админ-панели проверьте:
- ✅ `telegram_enabled` = `1` (интеграция включена)
- ✅ `telegram_verified` = `1` (бот проверен)
- ✅ `telegram_bot_token` заполнен (токен бота)

## Возможные проблемы

### Пользователи не получают сообщения

1. **Проверьте настройки бота:**
   - Бот включен и проверен в админ-панели
   - Токен бота правильный
   - Вебхук настроен

2. **Проверьте привязку пользователя:**
   - Пользователь привязал Telegram через код верификации
   - Или указал Telegram username/chat_id в профиле

3. **Для рассылок:**
   - Убедитесь, что выбран метод доставки "Telegram"
   - Пользователь указал Telegram в профиле (для рассылок используется поле `telegram`, а не привязанный аккаунт)

### Бот не отвечает на команды

1. Проверьте, что вебхук настроен правильно
2. Проверьте логи сервера на наличие ошибок
3. Убедитесь, что URL вебхука доступен из интернета (не localhost)

### Ошибка "Telegram бот не проверен"

1. Нажмите "🔍 Проверить подключение" в настройках
2. Убедитесь, что токен бота правильный
3. Проверьте, что сервер может подключиться к Telegram API

## Команды бота

После настройки пользователи могут использовать:
- `/start` - начало работы с ботом
- `/menu` - показать меню бота
- `/verify <код>` - верификация аккаунта
- `/events` - список мероприятий
- `/assignments` - список заданий пользователя
- `/faq` - ссылка на FAQ
- `/rules` - ссылка на правила

Администратор может настроить дополнительные команды через **Настройки → Интеграции → Telegram → Управление меню бота**.

## Технические детали

### Таблицы базы данных

- `telegram_users` - привязанные Telegram аккаунты пользователей
  - `user_id` - ID пользователя
  - `telegram_chat_id` - Chat ID в Telegram
  - `telegram_username` - Username пользователя
  - `verified` - статус верификации
  - `verification_code` - код для верификации

- `telegram_bot_menu` - меню бота (команды и кнопки)

- `settings` - настройки интеграции
  - `telegram_bot_token` - токен бота
  - `telegram_chat_id` - Chat ID для уведомлений
  - `telegram_enabled` - включена ли интеграция
  - `telegram_verified` - проверен ли бот
  - `site_url` - канонический базовый URL сайта (для бота и ссылок)
  - `gwars_domain_map` - карта доменов GWars (см. [GWARS_DOMAINS.md](GWARS_DOMAINS.md))

### API endpoints

- `POST /telegram/webhook` - получение сообщений от Telegram
- `POST /telegram/verify/generate` - генерация кода верификации
- `GET /telegram/verify/status` - проверка статуса верификации
- `POST /telegram/verify/unlink` - отвязка Telegram аккаунта
- `POST /admin/telegram/verify` - проверка подключения бота (админ)

### Функции отправки

- `send_telegram_message(message, chat_id, parse_mode)` - отправка простого сообщения
- `send_telegram_message_with_keyboard(message, chat_id, keyboard, parse_mode)` - отправка с клавиатурой
